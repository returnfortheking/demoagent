# v0.1 MVP Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 构建 HiSpark AI Agent MVP — Python Backend 实现意图分类 + 知识问答，VS Code Extension 将自然语言转为 VS Code 命令执行。

**Architecture:**
- Python Backend: FastAPI + 旧版 LLMChain/RetrievalQA（v0.2 重构为 LCEL 形成对比）+ Chroma 内存向量库
- TypeScript Extension: Webview + postMessage ↔ Extension Host → HTTP Client → FastAPI → Command Executor → vscode.commands.executeCommand
- Gradio: Python 侧独立调试 UI，不依赖 VS Code，最终产品 UI 在 Webview

**Tech Stack:** Python 3.11+, langchain 0.3.x, langchain-openai, FastAPI, Chroma, Gradio, pytest, pytest-mock | TypeScript, VS Code Extension API, Mocha, httpx

**Feature 覆盖:** F01–F14（见 feature-roadmap.md）

**测试分层策略:**
```
单元测试  → Mock LLM/HTTP，测逻辑正确性，每次 commit 必须全部通过
集成测试  → 真实 LLM + 真实 FastAPI，验证 Prompt 有效性，每版本打 tag 前运行
E2E 测试  → 全链路（FastAPI + Extension 行为模拟），验证系统整体正确性
```

## Task 10: 命令执行器 (F10)

**层次: 单元测试（依赖注入，不依赖 VS Code 运行时）**

### 接口定义

```typescript
// extension/src/executor/CommandExecutor.ts

// 使用依赖注入，使执行器可在测试中完全控制
type ExecuteFn = (command: string) => Promise<void>
type ConfirmFn = (message: string) => Promise<boolean>

class CommandExecutor {
  constructor(executeFn: ExecuteFn, confirmFn: ConfirmFn)
  handle(response: ChatResponse): Promise<void>
}
```

**handle 的行为规约:**
- `type !== 'action'` → 直接返回，不执行任何操作
- `type === 'action'` 且 `requires_confirmation === false` → 直接调用 executeFn
- `type === 'action'` 且 `requires_confirmation === true` → 先调用 confirmFn，返回 true 则执行，返回 false 则放弃

### 单元测试场景

**文件:** `extension/src/test/suite/commandExecutor.test.ts`
**策略:** 通过构造函数注入 mock 函数，无需 mock VS Code API

| # | 场景 | response 内容 | confirmFn 返回 | 期望 executeFn 调用 | 期望 confirmFn 调用 |
|---|------|-------------|---------------|-------------------|-------------------|
| 1 | 普通命令直接执行 | action, build, conf=false | 不会被调用 | 调用 1 次，参数为 build | 0 次 |
| 2 | 危险命令用户确认 | action, flash, conf=true | true | 调用 1 次，参数为 flash | 1 次 |
| 3 | 危险命令用户取消 | action, flash, conf=true | false | 0 次 | 1 次 |
| 4 | answer 类型忽略 | answer, 无 command | 不会被调用 | 0 次 | 0 次 |
| 5 | flash 确认消息含命令描述 | action, flash, conf=true, desc="烧录固件" | true | - | confirmFn 参数包含 "烧录固件" |


```json
  "results": [{ "id", "input", "expected_command", "predicted_command", "match" }]
```
